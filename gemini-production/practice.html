Sample lesson · About 5 minutes

Is this an AI case?

Three requests from a plant. Decide what each one really is before anyone talks about agents.

Fictional requests, modelled on typical production situations. No live systems.

01

Three words you will meet

RPA

Fixed rules, no model. Compares IDs, dates and thresholds; clicks through screens or moves data. Predictable, but it cannot read a messy document.

LLM step

A language model does one bounded task inside a fixed workflow: summarise, draft, extract, classify. Rules run before and after it; a person releases.

Agent

A model with tools and data that decides its next step within limits: look something up, check a rule, draft, escalate. It becomes an agent when it holds tools and data.

Routing comes before technology. Many requests are an SAP or MES topic and go to IT demand directly. That is a good result, not a failure.

02

Route three requests

For each request choose one: SAP or MES topic, fixed rule, LLM step, or agent. Then open the routing.

Request A · Warehouse

A new storage type for returned goods

The plant wants returned goods kept apart from new stock. Today they share one storage type, and pickers mix them up.

Show routing

SAP or MES topic.

A storage type is configuration in the system of record. No language model is needed. Route it to IT demand with the business reason. It may take time, but this path exists and keeps master data consistent.

Request B · Documentation

Work instructions as an 80 percent draft

Work instructions are written by hand for every product variant and printed. The team wants a first draft from existing documents, enriched with variant data from SAP, and a specialist who reviews and releases.

Show routing

LLM step in a workflow.

Fixed rules first: correct variant, plant, released revision, data not older than agreed. Then the language model drafts from approved documents and the variant data provided through the data layer. A specialist checks and releases. Nothing goes to the shop floor without that release.

Request C · Supply

Supplier order-status questions every day

Suppliers ask about order status by e-mail every day. The team wants a system that reads the question, finds the order in the data layer, decides whether it can answer or must escalate, and prepares the reply.

Show routing

Agent, with a human release at first.

Reading, looking up, deciding and drafting are several steps with tools and data: that is an agent. Limits: only approved data, no commitments on dates or quantities, escalation to a person when something is missing. A person sends the reply until the error rate is known.

03

Why routing first

A pure SAP topic does not wait for AI. A language-model step needs data, a rule check and a reviewer. An agent needs all of that plus tools and limits. Early routing gets ideas through IT faster and keeps the agent platform for cases that need it.
