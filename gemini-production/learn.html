02 · Draw the system and data map · Module preview

Understand the layers

SAP and MES record transactions and production events. An approved data layer can make selected information available for analysis. Google-based assistance works only with the data and tools it is allowed to use.

Output and check

Draw sources → approved provision → optional language assistance → expert review → controlled repository. Mark data owner, timestamp, access and unknown connections. This is a conceptual map, not a claim about available Kärcher connectors.

04 · Prepare the use-case interview · Module preview

Target pathway: Workspace Skill

Keep the structured problem/process/data interview and duplicate-check logic. Confirm the actual fields, databases and platform handoff with the process owner. An approved existing Gem is a transition.

Access and fallback

Workspace skills and standalone Gemini-app skills are separate. Licence, rollout and admin controls determine access. Without approved access, rehearse two questions offline; create or submit nothing.

05 · Responsible use and IT operation · Module preview

Keep the boundary visible

Use only approved tools and permitted data. Do not create local mini-apps with company data, obtain personal API keys or connect systems independently.

Name the accountable people

Identify the operator, IT support, process specialist, reviewer and release owner. Plan error handling and exceptions. A generated draft never becomes a released instruction through fluent wording alone.
