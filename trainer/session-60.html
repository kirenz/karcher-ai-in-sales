60-minute session: a pipeline overview and a short report

A ready-to-run session for sales colleagues, online or in a room. Everything the group works with is supplied, so nobody has to bring their own data.

← Prepare your session

Prepare30 minutes60 minutes90 minutes

What happens in these 60 minutes

Your colleagues use Gemini, Google’s AI assistant, inside Google Sheets, the spreadsheet application. Each person works on their own copy of the practice tracker: a prepared spreadsheet with twelve fictional customer accounts. Each row contains an industry, a sales stage, a value in euros and example notes. No real customer data is needed.

They start with the pipeline card, a page of exercise instructions, and copy its prompt: the ready-written request to Gemini. Gemini is asked to create a summary of the sales values on a new tab in the spreadsheet. The summary groups the values by sales stage and by industry, called a segment in this exercise. Each participant then adds the values of one small segment from the original rows and compares their sum with the summary.

The next exercise stays in the same spreadsheet and uses the report card. Its prompt asks Gemini for a short written sales update in ordinary sentences instead of a table: how much value sits in each stage, which open deals (deals still in progress, neither won nor lost) are the largest, and which accounts have had no recent contact. Participants then compare the main statements in that text with the rows they came from.

To close, participants choose a task from their own work where they could use the same approach. They explain what they would ask Gemini to do and how they would check its answer.

Prepare before the day

Try both exercises yourself before the session and allow about an hour for preparation. Check access to Sheets and Gemini in advance so there is time to resolve any problems. If Sheets, Gemini or prompts are new to you, work through the preparation guide first; it introduces them step by step and assumes no prior experience.

First exercise: make a table and check it

Input: your editable copy of the practice tracker, plus the prompt on the pipeline card. Use the supplied fictional data.

Prepare · 3 minutes · slide 5. Open the tracker and choose File → Make a copy. Ask participants to confirm that their own copy is editable. If a copy fails, pair them at a working device.

Produce · 10 minutes · slide 10. Open Ask Gemini in Sheets, paste the card’s prompt unchanged. Review any proposed plan before approving it. The intended output is a table of values by stage and segment on a new tab called pipeline value. Layout can vary.

Check · 5 minutes · slide 11. Each participant adds the values of one small segment from the original rows and compares that sum with the output. Tell a partner: “I checked these rows; my total was …; the output matched / differed by ….” If it differs, look at which rows were included and correct it before use.

If the table does not appear. If the answer shows only in the side panel, ask again specifically for the table on the named new tab. If a device still does not produce it, pair that person with a colleague who has the table on screen. The slide screenshots are examples; a participant’s own copy can look different.

Second exercise: a short report you can check

Input: the same copy of the tracker and the report card. Output: a few sentences of plain text covering the value in each stage, the biggest open deals and the accounts that need attention.

Produce · 8 minutes · slide 14. Copy the report prompt into Ask Gemini in the same sheet. If Gemini returns another table, ask again for plain sentences.

Check and read the result · 5 minutes · slides 14–15. Take the statements one at a time and look for them in the rows: verify one stage total, check the largest open deal against the value column, and find the reference date behind any claim about recent contact. Correct any statement the rows do not support, and keep the result as a practice draft.

Your own task · slide 16. Write three lines: a sheet from your own work that would suit this, the question you would ask, and the facts you would check in the source. Compare them with a colleague. If you have no such sheet, choose another suitable task from the platform and name its input and its check.

If time runs short

First shorten the six-minute pair round. If a larger delay remains, omit the report block (slides 12–15) as a unit and use that time to finish the pipeline task and its check. Keep a brief written step for the participants’ own task and the close. Say clearly what the group did not get to. Do not add the email exercise to a sixty-minute slot.

After the session

Note which task the group completed and where people got stuck; the next session starts from there. Anyone who wants to try it on their own list has the same card on the platform, and the platform link belongs in the meeting notes from now on.
