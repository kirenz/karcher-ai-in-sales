Your first four weeks

Four small moves on material that already exists. No launch event needed.

The first four weeks
  • Week one is your first session, prepared on the first-session page.
  • The weeks after that turn one session into a routine and a short note back.

← Trainer hub

You do not need a big launch. You need four small moves in four weeks, each on material that already exists. Everything linked here sits on the start page.

Before week one: prepare one session

  • Walk the first-session path: try the card yourself, read one run sheet, rehearse ten minutes with a colleague. About an hour.
  • Smoke-test the platform where you will show it: karcher-ai-sales.web.app loads and one card opens.
  • Check Workspace and Gemini access before the session, so there is time to resolve any problem. If one device does not work on the day, pair that person with a colleague.
  • Book the slot: 30, 60 or 90 minutes, whichever you can get.

Week one: run your first session

Run the run sheet you prepared, as it is written. Every participant leaves with one result they produced and checked themselves; that is the whole goal of the first session.

  • Follow the run sheet: slides, exercise, expected output, check, cut rule.
  • Protect the hands-on minutes; they matter more than finishing your slides.
  • End with the handoff: "now run the same recipe on one of your own accounts."
  • Put the platform link in the meeting notes; it stays there from now on.

Week two: the seven-day follow-up

A week later, ask one question in the team meeting: who used it again on their own work, and what came out? That answer is your real result, not the attendance list.

  • Ask the follow-up question and note the answers; the progress page has the wording.
  • Offer one short repeat for anyone who got stuck. Ten minutes, same card.
  • Name the card of the week: one use case, one habit.

Week three: the second group, or the longer format

  • Run the same run sheet for the next group, or step up to 60 or 90 minutes with the group you already had.
  • Only now, if a group needs something different, reach for the optional pre-survey and the playbook.
  • If leadership will not give you slots, use the pushback moves.

Week four: make it a rhythm, and say so

  • In the team meeting, keep asking: "what did you try, what did it save?"
  • Log your sessions while they are fresh, and send your first note to Sales Enablement: reach, independent reuse, one win, one blocker.
  • Set a checkpoint about thirty days out: "what did you actually use?"

If energy dips after week four, that is normal, and fixable.
